Collect Feedback: Adaptive Card

Provides an adaptive card for collecting simple feedback.

json Feb 25, 2026 #ai #copilot-studio #adaptive-cards #agents

This Adaptive Card is a simple, clean user feedback solicitation UI, most commonly used right after an AI agent/Copilot response in Microsoft Copilot Studio (or similar chat experiences like Teams, web chat, etc.).

Tip: Modify this adaptive card to suit your needs at https://adaptivecards.io/designer/

collect-feedback.json
{
  "type": "AdaptiveCard",
  "$schema": "http://adaptivecards.io/schemas/adaptive-card.json",
  "version": "1.6",
  "actions": [
    {
      "type": "Action.Submit",
      "title": "👍 Looks Good!",
      "data": {
        "MessageEvent": "Custom Feedback",
        "Like": true
      }
    },
    {
      "type": "Action.Submit",
      "title": "👎 Needs Work.",
      "data": {
        "MessageEvent": "Custom Feedback",
        "Like": false
      }
    }
  ],
  "body": [
    {
      "type": "ColumnSet",
      "columns": [
        {
          "type": "Column",
          "width": "auto",
          "items": [
            {
              "type": "Image",
              "url": "https://github.com/CopilotSWATTeam/copilot-studio-patterns/blob/main/icons/Duckppuccin.png?raw=true",
              "altText": "Your agent logo here.",
              "width": "50px"
            }
          ],
          "verticalContentAlignment": "Center"
        },
        {
          "type": "Column",
          "width": "stretch",
          "items": [
            {
              "type": "TextBlock",
              "text": "How did we do?",
              "wrap": true,
              "style": "heading",
              "color": "Accent"
            }
          ],
          "verticalContentAlignment": "Center"
        }
      ]
    },
    {
      "type": "Input.Text",
      "placeholder": "Any information you can share (feel free to copy and paste agent response here) is appreciated!",
      "id": "Comments",
      "isMultiline": true,
      "separator": true,
      "spacing": "Medium"
    }
  ]
}
